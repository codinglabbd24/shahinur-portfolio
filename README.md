# Shahinur Rahman Khan - Personal Portfolio & Blog Platform
### সফটওয়্যার ডেভেলপার ও উদ্যোক্তা পোর্টফোলিও ওয়েবসাইট

এই প্রজেক্টটি **Shahinur Rahman Khan**-এর একটি আধুনিক, রেসপন্সিভ এবং ইন্টারঅ্যাক্টিভ পার্সোনাল পোর্টফোলিও ওয়েবসাইট। এতে পোর্টফোলিও শোকেসের পাশাপাশি একটি সম্পূর্ণ ক্লায়েন্ট-সাইড **ব্লগ পাবলিশিং ও রিডিং প্ল্যাটফর্ম** অন্তর্ভুক্ত করা হয়েছে।

## 🌟 প্রধান বৈশিষ্ট্যসমূহ (Key Features)

1. **প্রফেশনাল হিরো সেকশন (Hero Section):**
   - শাহিনুর রহমান খানের ছবি, টাইটেল, এবং "Software Developer & Entrepreneur" ব্যাজ।
   - ইন্ডাস্ট্রি মেট্রিক্স (৫+ বছর অভিজ্ঞতা, ২৫+ সম্পন্ন প্রজেক্ট, ১০০% ক্লায়েন্ট সন্তুষ্টি)।
   - আধুনিক ফ্লুটিং ব্যাজ ও ইন্টারঅ্যাক্টিভ অ্যাকশন বাটন।

2. **সম্পূর্ণ ব্লগ প্রকাশনা ইঞ্জিন (Blog Publishing Engine):**
   - **✍️ নতুন ব্লগ লিখুন (In-Browser Blog Publisher):** যে কেউ সরাসরি ওয়েবসাইটে টাইটেল, ক্যাটাগরি, ট্যাগ, কভার ফটো ও মূল বক্তব্য (Markdown ফরম্যাট সহ) লিখে এক ক্লিকে ব্লগ প্রকাশ করতে পারেন।
   - **লোকালস্টোরেজ পারসিস্টেন্স (Persistent Storage):** নতুন প্রকাশিত সব ব্লগ ব্রাউজারের `localStorage`-এ স্বয়ংক্রিয়ভাবে সেভ থাকে, ফলে রিলোড করলেও হারিয়ে যায় না।
   - **📖 সম্পূর্ণ রিডার মোড (Full Blog Reader):** ব্লগে ক্লিক করলে সুন্দর টাইপোগ্রাফি, কোড ব্লক হাইলাইটিং, সোশ্যাল শেয়ার এবং অথর প্রোফাইল সহ সম্পূর্ণ ব্লগ পড়ার অভিজ্ঞতা।
   - **রিয়েলটাইম সার্চ ও ক্যাটাগরি ফিল্টার:** ক্যাটাগরি পিলস এবং সার্চ বার দিয়ে যেকোনো ব্লগ তাত্ক্ষণিক খুঁজে পাওয়া যায়।
   - **💾 ডেটা ব্যাকআপ ও এক্সপোর্ট (JSON Export):** এক ক্লিকেই সম্পূর্ণ ব্লগের ডেটা ব্যাকআপ হিসেবে ডাউনলোড করা যায়।

3. **প্রজেক্ট ও ভেঞ্চার শোকেস (Projects & Ventures):**
   - ক্যাটাগরি অনুযায়ী ফিল্টার (সফটওয়্যার প্রোডাক্টস, উদ্যোক্তা ভেঞ্চার, ক্লায়েন্ট সলিউশন)।
   - লাইভ ডেমো ও গিটহাব সোর্স কোড লিংক।

4. **ইন্টারঅ্যাক্টিভ স্কিলস ও টেক স্ট্যাক (Skills Grid):**
   - Frontend, Backend & Database, DevOps & Cloud, Entrepreneurship ফিল্টার সহ ডায়নামিক পার্সেন্টেজ বার।

5. **ডার্ক ও লাইট থিম (Dark / Light Mode Toggle):**
   - মসৃণ কালার প্যালেট ট্রানজিশন এবং ব্যবহারকারীর পছন্দ ব্রাউজারে সংরক্ষিত রাখা।

6. **যোগাযোগ ও কন্টাক্ট ফর্ম (Contact & Connect):**
   - সরাসরি ইমেইল সেন্ডার, হোয়াটসঅ্যাপ কুইক কানেক্ট এবং সোশ্যাল প্রোফাইল লিংক।

## 🚀 কীভাবে লোকালি রান করবেন (How to Run Locally)

### অপশন ১: সরাসরি ব্রাউজারে ওপেন করুন
যেকোনো ফাইল এক্সপ্লোরার থেকে `index.html` ফাইলটিতে ডাবল ক্লিক করুন বা ব্রাউজারে ড্র্যাগ অ্যান্ড ড্রপ করুন।

### অপশন ২: লোকাল সার্ভার দিয়ে রান করুন (Recommended)
টার্মিনালে এই কমান্ডটি চালান:
```bash
cd /home/shahin/.gemini/antigravity/scratch/shahinur-portfolio
python3 -m http.server 3000
```
এরপর যেকোনো ব্রাউজারে ভিজিট করুন:
👉 `http://localhost:3000`

## 🌐 ইন্টারনেটে ফ্রিতে লাইভ করার নির্দেশিকা (Free Deployment Guide)

### ১. Vercel দিয়ে লাইভ করুন (সবচেয়ে সহজ):
1. [vercel.com](https://vercel.com)-এ যান।
2. "Add New Project" ক্লিক করে এই ফোল্ডার বা আপনার গিটহাব রিপোজিটরি ইমপোর্ট করুন।
3. কোনো কনফিগারেশন পরিবর্তন ছাড়াই **Deploy** চাপুন। কয়েক সেকেন্ডে সাইটটি লাইভ হয়ে যাবে!

### ২. GitHub Pages দিয়ে লাইভ করুন:
1. GitHub-এ একটি নতুন রিপোজিটরি তৈরি করুন (যেমন: `portfolio`).
2. কোড পুশ করুন:
   ```bash
   git init
   git add .
   git commit -m "Initial commit of Shahinur Rahman Khan Portfolio"
   git branch -M main
   git remote add origin https://github.com/<your-username>/portfolio.git
   git push -u origin main
   ```
3. GitHub Repo-এর **Settings** > **Pages** ট্যাবে গিয়ে Branch হিসেবে `main` নির্বাচন করে সেভ করুন।
4. আপনার সাইট লাইভ হয়ে যাবে `https://<your-username>.github.io/portfolio` ঠিকানায়!
